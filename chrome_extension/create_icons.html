HRM Screen Capture Extension - Icon Generator

To create icons for the extension:

  1. Create simple 16x16, 48x48, and 128x128 pixel PNG images
  2. Name them: icon16.png, icon48.png, icon128.png
  3. Place them in the chrome_extension folder
  4. Or use any online icon generator tool

Quick Solution: You can use any simple icon or create a colored square with text "HRM" for now.

The extension will work without icons, but Chrome will show a default icon.
