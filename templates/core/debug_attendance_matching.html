💡 Solution for Ping Error:

If the machine is accessible but ping is failing (firewall blocking ICMP), you can disable the ping test:

  1. Go to Edit Machine
  2. In the "Configuration" JSON field, add: {"ommit_ping": true}
  3. Save and try connecting again

This will skip the ping test and connect directly via TCP. Some firewalls block ICMP (ping) but allow TCP connections on port 4370.
